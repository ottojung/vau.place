Vau place

a small logic detour

I tried to add numbers to a tree

I started by asking what happens if one adds something arithmetic-looking to Rabin's infinite binary tree. I expected a tree problem. The tree mostly disappeared.

tree→growth→powers→arithmetic
start

Rabin gives us a surprisingly large safe zone

The complete infinite binary tree can be written as T = {0,1}*: all finite binary strings. From a node w, the two child operations are S0(w) = w0 and S1(w) = w1.

Monadic second-order logic, or MSO, lets us quantify not only over nodes but also over sets of nodes. That sounds like a lot of power. Still, Rabin's tree theorem says that the MSO theory of (T, S0, S1) is decidable.

I find this kind of theorem hard not to poke at. Once you know there is a fairly expressive structure whose theory is decidable, the next question almost asks itself: how close is it to becoming undecidable? What small extra operation would push it over the edge?

first try

So I tried addition

Addition is an obvious suspect. The problem is that tree nodes are strings, not numbers, and there is no canonical operation that deserves to be called their sum.

My first instinct was therefore not to define a particular operation, but to ask for familiar algebraic laws: perhaps associativity, commutativity, a distinguished zero, and so on.

That went nowhere. Those laws say much less about “addition” than my intuition was smuggling in. Idempotent operations and semilattice-like operations can satisfy much of the same algebra while having no arithmetic growth at all. The missing ingredient was not another elegant algebraic law. It was growth.

too strong

The tree itself suggested a notion of positive

The tree already has an order. Write x ≼ y when x is a prefix of y, equivalently when x is an ancestor of y. This relation is MSO-definable from the two child operations, so using it does not secretly add new expressive power.

On ordinary non-negative numbers, positive addition grows past both inputs:

x, y > 0  ⇒  x + y > x and x + y > y.

I tried the analogous condition on the tree. It is impossible. Two nodes on unrelated branches have no common descendant, so there may be nowhere for a sum that must sit strictly beyond both of them.

This was the first useful failure. It forced me to separate “grows upward in this particular order” from the weaker thing I actually wanted: the operation should not collapse back into either input.

weaken

A tree-compatible positivity condition

Let ε be the root. I ended up with the following condition, which I will call positive growth:

x, y ≠ ε  ⇒  ¬(x + y ≼ x) and ¬(x + y ≼ y).

The result does not have to be a descendant of either summand. It is allowed to jump to an incomparable branch. The condition only forbids it from being an ancestor of, or equal to, either input.

This is deliberately weak. In particular, I no longer needed commutativity or an identity for the argument that followed. Associativity plus this small amount of growth turned out to be enough.

surprise

Repeated addition starts counting for us

Pick any non-root node a. Because the operation is associative, its powers are unambiguous:

a,  a² = a+a,  a³ = a+a+a,  …

Positive growth immediately rules out non-root idempotents: x+x = x would imply x+x ≼ x.

Now suppose two powers repeated, say a^i = a^j with i < j. From that point the powers would be periodic. Any finite monogenic semigroup contains an idempotent power, so some a^n would satisfy a^n a^n = a^n. Positive growth forbids that. Therefore all the powers of a are distinct.

And associativity gives the important equation:

a^m + a^n = a^(m+n).

At this point the operation has manufactured a copy of the positive integers under addition. The only remaining question is whether MSO can find that copy.

MSO

MSO can see the powers

Fix a and look at the one-step relation x ↦ x+a. MSO can define reachability along this relation with the usual closed-set trick: 

Reach_a(x, y) :=
  for every set X,
    if x ∈ X
       and X is closed under u ↦ u+a,
    then y ∈ X

The intersection of all such closed sets is exactly the orbit generated from x. Starting at a, MSO can therefore define

D_a = {a, a², a³, …}.

On D_a, our operation is just ordinary addition of exponents. So the expanded tree interprets (N>0, +). The full MSO theory of positive integers with addition is undecidable: MSO can define divisibility by talking about sets closed under addition by a fixed number, and classical arithmetic definability results then recover multiplication.

Therefore any associative operation on the binary tree satisfying positive growth makes MSO(T, S0, S1, +) undecidable.

This also answers the weaker question I started with. Such an operation cannot already be MSO-definable in Rabin's original tree, because adding a definable operation would preserve decidability.

and then the tree disappeared

The argument was barely about trees

Once I wrote the proof down, the embarrassing thing was how little of the tree remained in it.

The tree order was useful only to formulate a geometric condition that forced the powers of a to keep producing new elements. After that, the child relations, branches, prefixes, and even the root were doing no work.

The real mechanism is much more ordinary:

an element with infinitely many distinct powers → a definable monogenic subsemigroup → (N>0, +) → undecidable MSO

So the tree experiment suggests the following general statement:

If a semigroup contains an element of infinite order, then its full monadic second-order theory is undecidable.

Here “infinite order” only means that a, a², a³, … are all distinct. The generated subsemigroup is then literally a copy of the positive integers under addition.

There is one technical nuisance: the language need not name a particular infinite-order element. Fortunately MSO can handle that too. The property that the orbit of a has no directed cycle is MSO-expressible using the same reachability formula, so the interpretation can existentially choose a suitable a.

the parameter detail

Let D_a(x) mean that x is reachable from a by repeated right multiplication by a. Then a has infinite order exactly when no x ∈ D_a can be reached again from x·a. A finite orbit eventually enters a directed cycle; an orbit with all powers distinct never does.

This gives an MSO formula InfiniteOrder(a). To translate a sentence about (N>0,+), quantify an a satisfying that formula and relativize all number and set quantifiers to D_a.

An idempotent-free corollary

A finite monogenic semigroup always contains an idempotent. So if a nonempty semigroup has no idempotents at all, every element must have infinitely many distinct powers. The same argument then gives undecidable full MSO.

I like this conclusion mostly because it is so far away from the question that produced it. I started with the geometry of an infinite binary tree and with the vague idea that “addition should grow.” The useful object turned out to be the tiny one-generator semigroup hiding inside the operation.

I also do not want to oversell this as a new theorem. I did a limited literature search and found all of the ingredients, along with nearby undecidability results for monadic and finite-subset theories of algebraic structures, but I did not find this exact statement packaged in this exact way. That is weak evidence about terminology, not evidence of novelty. I would be surprised if such a short argument had escaped the literature.

References and nearby things

  1. Michael O. Rabin, “Decidability of Second-Order Theories and Automata on Infinite Trees” (1969). The starting point: the monadic second-order theory of the complete infinite binary tree is decidable. DOI
  2. Raphael M. Robinson, “Restricted Set-Theoretical Definitions in Arithmetic” (1958). A classical source around what monadic set quantification can define in arithmetic. DOI
  3. Julia Robinson, “Definability and Decision Problems in Arithmetic” (1949). Among the classical definability facts used in the arithmetic undecidability story is that multiplication can be recovered from successor and divisibility. DOI
  4. Monogenic semigroups. The standard finite picture is eventual periodicity with a unique idempotent in the cyclic part. This is the small semigroup fact used when repeated powers are ruled out. Encyclopedia of Mathematics
  5. Sergey Dudakov, “On Undecidability of Finite Subsets Theory for Torsion Abelian Groups” (2022). This is not the same theory as the one discussed here, but it is a useful nearby result: finite-subsets theories of monoids with infinite-order elements have closely related arithmetic interpretations.
