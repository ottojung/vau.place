Addition on Rabin's tree

<FACT>
The structure is the complete infinite binary tree T = {0,1}*: all finite binary strings. The empty string ε is the root. The two children of w are w0 and w1.
<IMAGINE A BEAUTIFUL INFINITE BINARY TREE HERE>
<EXAMPLE>
The first few levels are ε, then 0, 1, then 00, 01, 10, 11, and so on.
<FACT>
The tree has a natural prefix/ancestor order. Write x ≼ y when x is a prefix of y, equivalently when x is an ancestor of y.
<EXAMPLE>
0 ≼ 0101. The nodes 00 and 11 are incomparable. This order is not like the total order of the natural numbers.
<FACT>
First-order logic quantifies over individual nodes. Monadic second-order logic, MSO, also quantifies over arbitrary sets of nodes.
<INTENT>
Explain this without assuming the reader knows model theory. “The theory of a structure” means the collection of sentences true in that structure. “Decidable” means there is an algorithm that takes any sentence in the logic and eventually answers whether it is true.
<FACT>
Sets make MSO expressive on trees. They can describe paths and closed collections of nodes, and they can be used to define reachability-like notions.
<FACT>
The ancestor order ≼ is MSO-definable from the two child relations. One closed-set formulation is: every set containing x and closed under children also contains y.
<FACT>
Rabin's tree theorem says that the MSO theory of the complete infinite binary tree is decidable.
<CONTEXT>
Infinite trees are natural models of branching behaviour. A node may represent a finite history or state, and its children possible next steps. MSO is closely connected with tree automata.
<INTENT>
The interesting question is the boundary of this decidability result. If another operation or relation is added to the tree, does the theory remain decidable?
<MOTIVATION>
Arithmetic is a natural thing to test because many undecidability arguments proceed by interpreting enough arithmetic inside another structure.
<QUESTION>
What happens if the binary tree is equipped with an operation that behaves a little like addition?
<PROBLEM>
There is no canonical addition of tree nodes. The nodes are binary strings, not numbers. Therefore the experiment has to begin by deciding what “addition-like” should mean.
<FAILED-IDEA>
Associativity, commutativity, and an identity are too weak. After choosing an arbitrary total order of the nodes with ε first, max is associative, commutative, has ε as an identity, and is idempotent. These laws do not force arithmetic-like growth.
<INTENT>
The missing intuition was growth: adding nonzero things should not simply collapse back into one of them.
<FAILED-IDEA>
On ordinary positive numbers, x,y > 0 ⇒ x+y > x and x+y > y. The direct tree analogue would require x+y to be a strict descendant of both inputs.
<FACT>
The direct analogue is impossible on a branching tree. Nodes on different branches do not have a common descendant.
<SHOW TWO INCOMPARABLE BRANCHES AND WHY NO NODE CAN BE BELOW BOTH>
<INTENT>
This failure should motivate weakening “the result is above both inputs” to “the result is not at or below either input”.
<DEFINITION>
Let ε be the root. Call an associative operation + positively growing when
x,y ≠ ε  ⇒  ¬(x+y ≼ x) and ¬(x+y ≼ y).
<CAVEAT>
“Positive growth” is convenient terminology for this post. Do not present it as established terminology.
<FACT>
The condition does not require x+y to be above either argument. The sum may jump to an incomparable branch.
<FACT>
Commutativity and a zero law are not needed for the undecidability argument. Associativity and enough growth to keep powers from collapsing are the relevant parts.
<FACT>
Positive growth rules out non-root idempotents. If x ≠ ε and x+x=x, then x+x ≼ x, contradicting the condition.
<CONSTRUCTION>
Pick a non-root element a and consider its powers: a, a²=a+a, a³=a+a+a, …. Associativity makes these powers unambiguous.
<FACT>
If two powers repeated, say a^i=a^j for i<j, the generated monogenic semigroup would be finite and eventually periodic.
<FACT>
Every finite monogenic semigroup contains an idempotent power. That would contradict positive growth. Therefore a, a², a³, … are all distinct.
<FACT>
Associativity gives
a^m + a^n = a^(m+n).
Thus the powers of one element already form a copy of the positive integers under addition.
<VISUALLY TURN THE POWER SEQUENCE a, a², a³, … INTO 1, 2, 3, …>
<PROBLEM>
Merely having a copy of (N>0,+) inside the structure is not enough. The logic must be able to define the copy.
<FACT>
MSO can define reachability under the step x ↦ x+a by quantifying over every set that contains the starting point and is closed under this step.
<FORMULA-SKETCH>
Reach_a(x,y) :=
  for every set X,
    if x ∈ X
       and X is closed under u ↦ u+a,
    then y ∈ X
<FACT>
Therefore MSO can define D_a = {a,a²,a³,…}. Restricted to D_a, the operation is ordinary addition of exponents.
<RESULT>
An associative operation on the complete infinite binary tree satisfying positive growth makes MSO(T,S0,S1,+) undecidable, because the expanded structure interprets (N>0,+).
<COROLLARY>
Such an operation cannot already be MSO-definable in Rabin's original tree. Adding a definable operation would preserve the decidability of the original theory.
<OBSERVATION>
At this point almost all of the tree-specific structure has disappeared from the proof. The tree order supplied one convenient condition that forced repeated powers to stay distinct. The arithmetic comes from the monogenic subsemigroup.
<LET THE TREE FADE AWAY AND LEAVE ONLY a → a² → a³ → …>
<GENERALIZATION>
The same argument gives: if a semigroup contains an element of infinite order — an element a for which a,a²,a³,… are all distinct — then its full MSO theory is undecidable.
<TECHNICAL-DETAIL>
The language does not need to name a particular infinite-order element. MSO can express that the orbit generated by a has no directed cycle, existentially choose such an a, and relativize the interpretation to its generated subsemigroup.
<COROLLARY>
A finite monogenic semigroup contains an idempotent. Therefore every nonempty idempotent-free semigroup has an element of infinite order; in fact every element has infinite order. Its full MSO theory is therefore undecidable by the same argument.

Do not claim novelty. A preliminary search found the ingredients and nearby results, but not the exact general statement under this wording. That is weak evidence about terminology, not evidence that the theorem is new.
